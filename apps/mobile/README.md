# SIcoinX Mobile (React Native / Expo)

The SIcoinX customer wallet app for Android and iOS. It replaces the earlier Flutter app and talks to the
same Express API (`apps/api`) as the website.

**Stack:** Expo SDK 58 · React Native 0.88 · React 19 · Expo Router (file-based routes) · TypeScript (strict) ·
`decimal.js` for exact money math · `expo-secure-store` for the session token.

## Features

| Area | What it does |
| --- | --- |
| Auth | Sign in (with 2-factor code step when the account has MFA), register, session restore on launch, sign out (revokes the server session), automatic sign-out when the session expires |
| Wallet | Balance with INR/USD valuation, reference buy/sell rates, recent activity, pull-to-refresh, auto-refresh when returning from a purchase/sale/transfer, frozen-wallet notice |
| Buy | Rate-based total, min/max limits from the server, Razorpay **sandbox** checkout, receipt |
| Sell | Bank payout request with IFSC/account validation, available-balance check |
| Transfer | To another SIcoinX user (email / wallet ID) or a connected app (YouPeak, YouPeak Shop) |
| History | Filterable, paginated ledger with transaction receipts |
| KYC | Status (pending / approved / rejected with reason), document photo upload from the photo library |
| Support | Create tickets, read the conversation, reply |

## Run it

```bash
# 1. Start the API (repo root, separate terminal)
npm run setup          # first time only: install, build, migrate, seed
npm run dev -w apps/api

# 2. Install and start the app
cd apps/mobile
npm install
npm start              # then press "a" (Android), "i" (iOS), or scan the QR with Expo Go
```

In development the app finds the API automatically: it uses the same machine that serves Metro, on port 5000,
so a phone on the same Wi-Fi works with no setup. To point at another server, copy `.env.example` to `.env`
and set `EXPO_PUBLIC_API_URL` (origin or full `/api/v1` URL). **Release builds require `EXPO_PUBLIC_API_URL`**
and should use HTTPS.

The seed creates staff accounts only. Create a customer account with **Create an account** in the app.

## Firebase (Analytics)

Firebase project `sicoinx`, Android app `sicoinx.app`, via React Native Firebase.

- Config lives in `google-services.json` (project root) and is referenced from `app.json` (`android.googleServicesFile`);
  the `@react-native-firebase/app` config plugin applies the Google Services Gradle plugin for you, so
  **don't edit `android/` by hand**.
- The Android package in `app.json` must equal the `package_name` in `google-services.json` (`sicoinx.app`).
- Firebase uses native code, so it needs a **development build**, not Expo Go (Expo Go still runs the app; analytics is
  simply a no-op there):

  ```bash
  npx expo run:android        # local build, needs Android Studio + SDK
  # or a cloud build: npx eas-cli@latest build --profile development --platform android
  npx expo start --dev-client # then open the installed development build
  ```
- Events are sent through `src/lib/analytics.ts` (never throws, no personal data): `screen_view` per route, `login`,
  `sign_up`, `purchase`, `sell_request`, `coin_transfer`, `kyc_submitted`, `support_ticket_created`; the user id is the
  opaque server UUID. Watch them live in Firebase **DebugView**.
- iOS is not configured: add `GoogleService-Info.plist` (`ios.googleServicesFile`) from the Firebase console first.

## Project layout

```
src/app/            Expo Router routes: sign-in, register, (app)/(tabs)/…, buy, sell, transfer, ticket/[id]
src/api/            fetch client (timeouts, safe JSON parsing, typed errors), endpoints, response types
src/auth/           SessionProvider (secure token storage, route guard state)
src/components/     UI building blocks
src/lib/            money, formatting, validation, data-loading hook
```

## Notes

- **Payments are sandbox only.** When the API runs without live Razorpay keys it hands the app a matching
  payment id and signature, and the app confirms the simulated payment. If the server is configured with live
  keys the app says so instead of pretending to charge: opening real Razorpay Checkout needs the native
  Razorpay SDK, which requires a development build and is not integrated yet.
- `android/` and `ios/` are generated by Expo (Continuous Native Generation) and are git-ignored. Create builds
  with `npx expo run:android|ios` or Expo's cloud build service.
- Bundle identifier / Android package is `sicoinx.app`. The Android package must match `google-services.json`; change both together.
